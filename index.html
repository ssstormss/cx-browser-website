CX Browser — Version 0.2.1

Dein eigener Browser.
Von Grund auf gebaut, nicht nachgebaut.

CX ist kein Chrome mit neuem Anstrich, sondern eine eigenständige Electron- und React-Anwendung: eigene Tab-Verwaltung über WebContentsView, eigene Adressleiste, eigene Sicherheitsarchitektur – und ein Auto-Update-System, das jedes Update vor der Installation gegen SHA-256-Prüfsummen und die Authenticode-Signatur prüft.

Sicherheit

Abgesichert, nicht nur behauptet.

Die Sicherheitsarchitektur ist kein Feature-Häkchen, sondern die Grundlage, auf der alles andere läuft.

✓

contextIsolation, Sandbox und kein Node-Zugriff – auf jeder einzelnen Seite, ausnahmslos.

✓

Streng validierte IPC-Kanäle: die interne API window.cx wird ausschließlich auf CX-eigenen Seiten freigegeben, niemals auf einer geladenen Webseite.

✓

Geprüfte Updates: jedes Update wird vor der Installation per SHA-256 gegen die Release-Metadaten und zusätzlich per Authenticode-Signatur geprüft.

✓

Automatischer Rollback: drei gescheiterte Starts nach einem Update setzen CX Browser automatisch auf die vorherige Version zurück.

✓

Zertifikatsfehler lassen sich nur pro Sitzung ignorieren, nie dauerhaft – nach einem Neustart wird erneut gefragt.

Ehrlich, nicht nur beworben

Die Authenticode-Prüfung läuft bereits vollständig, meldet aktuell aber ehrlich NotSigned zurück – es gibt noch kein Code-Signing-Zertifikat für CX-Releases. Updates werden deshalb bewusst nicht blockiert. Sobald signiert wird, greift die Prüfung ohne weitere Codeänderung.
